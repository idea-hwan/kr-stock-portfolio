## 1. 선정 논리 — 신호 체계

밸류주 버킷은 **28분기 연속 흑자**를 유지한 안정적 기업들의 집합이다.  
이 버킷에서 성과를 결정하는 것은 하나 — **얼마나 싸게 샀는가**.

### 핵심 신호

```
per_ratio = per_op_20d / per_op_4y   (op → ni → rev 우선순위 폴백)

per_ratio < 0.5   →  매수
per_ratio ≥ 0.5   →  매수 없음
```

### KT `ratio 0.79 | delta -1.28 | CF 부진 원인: 일시적`

**현금흐름 악화 원인**  
2024년 4분기 희망퇴직 비용 ~1조원 일회성 충격. 영업이익 -50.9%, 4분기 영업손실 -5,279억.  
2025년 구조조정 완료 후 연간 순이익 +340% 회복. 인건비 연 3,000억 절감 효과 가시화.

**현황**  
- 2025년 연간 순이익 1조 8,369억원, 매출 28조 2,442억원  
- AI·보안·데이터센터(가산 26MW) 투자 지속 → CAPEX는 구조적으로 높은 수준 유지  
- 통신사 특성상 완전한 FCF 정상화는 단계적

**판단**  
CF 악화의 직접 원인(구조조정 비용)은 **완전히 일시적**. 이미 회복 중.  
delta -1.28은 57종목 중 가장 빠른 ratio 하락. 조만간 0.5대 진입 가능성.  
★ **ratio 0.5 접근 시 최우선 관찰 대상**

**판단**  
CFO는 증가 중, FCF 악화는 순수하게 성장 설비 투자 탓. **완전 일시적**.  
불닭 수출 성장이 지속되는 한 구조적 훼손 없음.
