## 1. 핵심 원칙 (확정)

```
적당히 저평가되어 있고(per_ratio 0.5~1.0), 영업이익이 적당히 가속하는
(acceleration 2~5배) 종목을 산다.

너무 싼 것(<0.5)도, 너무 안 싼 것(≥1.0)도 아니다.
너무 안 크는 것(<2배)도, 너무 급하게 크는 것(≥5배)도 아니다.
```

극단(가장 싸다, 가장 빨리 큰다)이 아니라 **중간 구간**이 이긴다는 게 핵심이다. 가장 싼
구간(<0.5)과 가장 급가속하는 구간(≥5배)은 둘 다 alpha가 마이너스였다 — 전자는 유틸리티·
지주회사처럼 구조적으로 저PER인 종목이 섞여 있던 착시였고, 후자는 기저효과(적자 근처
저점 대비 회복)로 인위적으로 부풀려진 가속인 경우가 많았다.

## 3. 확정 신호

```
Signal A (저평가) = per_ratio = per_op_20d / per_op_4y   (영업이익 기준, op→ni→rev 폴백)
Signal B (가속)   = acceleration = op_geom_1y_mcum / op_geom_4y_mcum

매수 신호 = 0.5 ≤ per_ratio < 1.0   AND   2 ≤ acceleration < 5
```

## 4. 백테스트 근거 (growth_pit16, n=2468, KOSPI200 대비 alpha)

| | n | raw mean/median | **alpha mean/median** |
|---|---|---|---|
| 전체(baseline) | 2468 | +24.5% / +0.9% | -6.4% / -9.4% |
| **확정 신호: ratio[0.5,1) + accel[2,5)** | **162** | **+27.4% / +5.2%** | **+10.1% / +2.1%** |
| (참고) ratio<0.5 단독 | 345 | +17.2% / +1.7% | -8.8% / -9.5% |
| (참고) accel≥2 단독 (상한 없음) | 541 | +21.7% / +0.8% | +0.7% / -3.4% |

이 유니버스 전체가 시장(KOSPI200) 대비 alpha -6.4%로 계속 졌던 와중에, 확정 신호만
**mean·median 둘 다 플러스**(+10.1%p / +2.1%p, baseline 대비 +16.5%p 우위)다. n=162로
이 전략에서 다룬 조합 중 가장 표본이 크면서 동시에 median까지 살아있는 유일한 신호다.

보유기간을 늘리면 mean은 더 커지지만(12m +10.1% → 15m +12.7% → 18m +23.3%) **median은
15m부터 마이너스로 돌아선다**(-2.0%) — 평균은 소수 대박 종목이 끌어올리는 구조이므로,
포지션은 12m 관점으로 보수적으로 잡는다.

alpha는 특정 구간(2025~2026)에서 벤치마크 왜곡으로 실제 손익과 어긋날 수 있다 — 항상 raw와
같이 보고, 배경은 §7.3 참고.

## 6. 매수 기준

```
매수: 0.5 ≤ per_ratio < 1.0  AND  2 ≤ acceleration < 5
      → alpha mean +10.1%, median +2.1%(n=162)

해당 없음 → 매수 없음. 특히 per_ratio < 0.5(극단 저평가)나
acceleration ≥ 5(급가속)를 "더 좋은 신호"로 착각하지 않는다 — 둘 다 오히려 나쁘다.
```

## 7. 매도 확정 신호 (run_id=6 / as_of=2026-07-23)

us-stock-portfolio의 매도 신호 방법론(성장꺾임·고평가·투자압박 3축 그리드서치, 3/6/9개월
alpha 기준)을 KR growth_pit16에 이식해 재검증했다. P/FCF는 fcf_ps(roll4 TTM, FY우선폴백
없음) 그대로 쓴 간이 버전 — 결측이 P/OP·P/NI보다 많다.

```
매도: ni_1y↓(순이익 1년 역성장) AND cfo_1y↓(영업현금흐름 1년 역성장)
      AND P/NI 고평가(per_ni_20d / per_ni_4y > 1.25)

→ n=148, 74종목, 2020Q3~2026Q1
  raw 수익률   mean/median: 3m +3.2%/-0.1%, 6m +8.3%/-0.9%, 9m +13.3%/-2.6%, 12m +12.2%/-3.7%
  alpha(KOSPI200) mean/median: 3m -11.7%/-12.3%, 6m -15.6%/-12.3%, 9m -25.7%/-17.2%, 12m -35.2%/-22.0%
```

alpha만 보면 보유 기간이 늘수록 크게 악화하는 것처럼 보이지만, **raw median은 -0.1%~-3.7%로
소폭 마이너스에 그치고 mean은 오히려 플러스(+3~13%)**다 — 매도 신호가 잡은 종목이 "폭락"하는
게 아니라 "지수보다 못하다"는 뜻에 가깝다. alpha의 극단적인 악화는 상당 부분 벤치마크 왜곡
때문이다(§7.3 참고). 그래도 baseline·홀딩군 대비로는 raw·alpha 둘 다 일관되게 나쁜 방향이라
매도 판단 자체는 유지한다.

세 조건이 동시에 필요하다 — 순이익·현금흐름이 같이 꺾이고 밸류에이션까지 비싸진
경우만 잡는다. 개별 조건 단독으로는 신호가 약하거나(P/NI_고평가 단독 n=514,
alpha 3~12m -6.9~-12.1%) 아예 반대 방향으로 나온다(아래 §7.1).

### 7.3 벤치마크(KOSPI200) 유의사항 — 반드시 raw와 같이 볼 것

2026-07-23 out-of-sample 점검 중 발견: 2025~2026 구간에 삼성전자(12개월 +372%)·SK하이닉스
(12개월 +807%, AI/HBM 랠리로 추정)가 폭등하면서 KOSPI200(mcap200 시총의 55.5%가 이 두
종목)이 같은 기간 2~4배 뛰었다. 두 종목은 성장주 매수 신호(§3)를 한 번도 충족한 적이 없다 —
삼성전자는 저평가 구간(ratio 0.6대)에 들어온 2024Q4~2025Q1 시점에 하필 4년 기저 마이너스로
가속도(accel)가 NaN이었고, SK하이닉스는 2023년 실적 급락으로 growth_pit16 자체에서 이탈해
이후 랠리에 복귀할 방법이 없었다(16분기 연속 흑자 조건은 한 번 깨지면 재편입 불가). 즉 우리
유니버스가 구조적으로 담을 수 없는 종목 2개가 벤치마크만 밀어올린 셈이다.

그 결과 이 구간에서는 alpha가 실제 손익과 무관하게 전반적으로 나쁘게 나온다 — 예를 들어
매수 신호(§3)의 2025년 이벤트는 raw 수익률 median +33.8%(실제로 잘 벌었다)인데 alpha는
-82.2%로 나온다. **alpha를 1차 지표로 계속 쓰되, 판단할 때는 항상 raw 수익률을 같이 봐야
한다** — 이 문서의 표에 raw를 병기하는 이유다. 신호 공식 자체는 바꾸지 않는다(리스크 대비
효과가 불확실).
