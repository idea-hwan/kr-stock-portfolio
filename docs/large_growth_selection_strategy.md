## 1. 핵심 원칙

```
성장이 가속하는 초기 구간에서, 저평가된 종목을 산다.
성장이 식거나 비싸지면 판다.
```

성장주 버킷은 28분기 연속 영업이익 흑자 + 1y·2y·4y 성장 모두 양수 + 2y > 4y 조건을 통과한 종목들이다.  
버킷 내 성과를 결정하는 것은 두 가지 — **얼마나 싼가** + **성장이 지금 가속하고 있는가**.

## 3. 핵심 신호

### Signal A — 싸다 (per_ratio)

```
per_ratio = per_op_20d / per_op_4y     ← 영업이익 기준 우선 (op → ni → rev 폴백)

per_ratio < 0.5   →  매수 1순위
per_ratio < 1.0   →  매수 가능
per_ratio ≥ 1.0   →  관찰 / 매수 자제
```

### Signal B — 성장 가속 (acceleration)

```
acceleration = op_geom_1y / op_geom_4y   (단, op_geom_4y > 0 기준)

acceleration ≥ 2   →  성장 초기·가속 구간
  = 최근 1년 성장률이 4년 CAGR의 2배 이상
  = 성장이 최근 들어 역사적 평균보다 훨씬 빨라진 상태
```

> **이 두 신호의 조합이 핵심.** per_ratio < 0.5 + acceleration ≥ 2 → 백테스트 최고 성과 구간.

## 5. 보조 신호

### CAPEX 확대

```
capex_geom_1y > 0   →  성장 투자 진행 중 (긍정 신호)
```

| 조건 | n | mean | median |
|------|---|------|--------|
| capex_g1 > 0 | 386 | +24.3% | +5.5% |
| capex_g1 ≤ 0 | 256 | +17.2% | +7.0% |

> CAPEX 확대는 성장 지속성 확인 보조 지표. 단독 신호로는 약함. 핵심 신호와 함께 볼 것.

### FCF (현금흐름) — 주의 필요

```
FCF 해석이 per_ratio 구간별로 반대로 작동한다.
```

| 조건 | n | mean | median |
|------|---|------|--------|
| ratio < 0.5 + FCF ≥ 0 | 51 | +34.7% | +27.6% |
| ratio < 0.5 + FCF < 0 | 17 | +16.5% | +5.5% |
| ratio 0.5~1.0 + FCF < 0 | ~88 | +25.0% | +8.4% |
| ratio 0.5~1.0 + FCF ≥ 0 | ~319 | +17.2% | +4.7% |

> **ratio < 0.5 구간**: FCF 양수가 훨씬 강함. "싸고 현금도 창출" = 시장 미발견 진짜 저평가.  
> **ratio 0.5~1.0 구간**: FCF 음수가 다소 강함. 투자 국면의 성장주 특성.  
> FCF는 참고 지표. 필터로 쓰지 않는다.

## 6. 매수 기준

```
1순위: per_ratio < 0.5 + acceleration ≥ 2
       → 평균 +60.7%, 중앙값 +52.5%, 손실 -20% 이하 확률 3%

2순위: per_ratio < 0.5 (단독)
       → 평균 +37.8%, 중앙값 +26.2%

3순위: per_ratio < 1.0 + acceleration ≥ 2
       → 평균 +34.8%, 중앙값 +10.7%

해당 없음 → 매수 없음
```

가능하면 CAPEX 증가 동반 여부를 보조 확인.

---

## 7. 홀딩 기준

```
per_ratio < 1.5  →  홀딩
per_ratio ≥ 1.5  →  매도 검토
per_ratio ≥ 2.0  →  매도 (단, 강한 성장 사이클 지속 중이면 신호 보며 유지)

acceleration 감소 시 (og1 < og4):
  → 성장 둔화 신호. ratio 무관하게 매도 검토 시작
```

---

## 8. 매도 기준

```
1순위: acceleration < 1 (og1 < og4) + per_ratio ≥ 1.5  →  매도
2순위: per_ratio ≥ 2.0 (단독)                           →  매도 검토
3순위: acceleration < 1 (단독)                           →  매도 검토 (성장 둔화 확인)
```
