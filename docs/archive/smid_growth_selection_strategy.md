## 1. 핵심 원칙

```
싼 것을 산다.
가속 신호는 쓰지 않는다.
```

중소형 성장주는 대형 성장주와 **논리는 같지만 신호 체계가 다르다.**  
대형에서 위력적이었던 성장 가속 신호(acceleration)가 중소형에서는 **오히려 수익률을 낮춘다.**  
중소형 이익은 변동성이 크고 일회성 요인에 쉽게 왜곡되기 때문 — 급가속은 구조적 성장이 아닌 노이즈일 가능성이 높다.  
**per_ratio 단독이 최선의 전략이다.**

---

## 2. 유니버스

`data/analytics/smid_growth_stock.csv`

| 조건 | 내용 |
|------|------|
| 시총 | `mcap_top_200.csv` 미편입 (중소형) |
| 이익 안정성 | 최근 28분기 연속 `ni_parent_ps > 0` |
| 성장 조건 | `ni_geom_1y`, `ni_geom_2y`, `ni_geom_4y` 모두 > 0 |
| 가속 조건 | `ni_geom_2y > ni_geom_4y` |
| 현재 종목 수 | 52개 (2025Q4 기준) |

> 버킷 분류는 순이익(ni) 기준. per_ratio 계산은 op → ni → rev 우선순위로 폴백.

---

## 3. 핵심 신호 — per_ratio (싸다)

```
per_ratio = per_op_20d / per_op_4y     ← 영업이익 기준 우선 (op → ni → rev 폴백)

per_ratio < 0.5   →  매수
per_ratio ≥ 0.5   →  매수 없음
```

중소형 성장주도 per_ratio가 **유일한 핵심 신호**다.

## 5. op 기준 vs ni 기준 — 결론

```
op 가속:  역효과가 더 크다  (ratio<0.5 → +8.8%)
ni 가속:  역효과가 다소 작다 (ratio<0.5 → +11.8%)
단독:     per_ratio만이 최선 (ratio<0.5 → +18.2%)
```

→ **영업이익이든 순이익이든 가속 필터는 쓰지 않는다.**  
→ 버킷 분류가 ni 기반이어도, 선정은 per_ratio 단독으로 충분.

---

## 6. 매수 기준

```
per_ratio < 0.5  →  매수

해당 없음  →  매수 없음
```

가속 신호(op or ni), CAPEX, FCF는 참고용으로만 활용.  
FCF가 양수인 종목을 우선하되, 필터로 쓰지 않는다.

---

## 7. 홀딩 기준

```
per_ratio < 1.0  →  홀딩
per_ratio ≥ 1.0  →  매도 검토
per_ratio ≥ 1.5  →  매도
```

중소형은 이익 변동성이 크므로 홀딩 기준을 대형 밸류주와 동일하게 보수적으로 운영.

---

## 8. 매도 기준

```
1순위: per_ratio ≥ 1.5      →  매도
2순위: per_ratio 1.0 이상   →  매도 검토 시작
```
