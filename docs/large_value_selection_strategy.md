## 3. 핵심 신호 — 싸다 (per_ratio)

```
per_ratio = per_op_20d / per_op_4y     ← 영업이익 기준 우선
            (결측 시 per_ni, 그 다음 per_rev 순 폴백)

per_ratio < 0.5   →  매수 대상
per_ratio ≥ 0.5   →  매수 없음
```

- `per_op_4y`: 최근 4년 평균 영업이익 기준 PER
- `per_op_20d`: 최근 20일 평균 주가 기준 영업이익 PER

## 5. 매수 기준

```
per_ratio < 0.5  →  매수

해당 종목 없음   →  매수 없음 (시장이 비싼 것)
```

현금흐름(cfo, fcf) 상태는 참고 지표로만 활용한다.
나쁠수록 반등 강도가 강해지는 경향이 있으나, 매수 필터로는 쓰지 않는다.

---

## 6. 홀딩 기준

```
per_ratio < 1.0  →  홀딩
per_ratio ≥ 1.0  →  매도 검토
per_ratio ≥ 2.0  →  매도
```

> 미결: 홀딩 상단 임계값(1.0 vs 1.5 vs 2.0) 백테스트 검증 필요.

---

## 7. 매도 기준

```
1순위: per_ratio ≥ 2.0     →  매도
2순위: per_ratio 1.0 이상   →  매도 검토 시작
```
