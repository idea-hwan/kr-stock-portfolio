# 대형 경기순환주 매수/홀딩/매도 선정 전략

> 기준: 2025Q4 / 대상: 코스피200 글로벌 경쟁력 경기순환주 34종목

---

## 1. 종목 분류 기준

### 대형 경기순환주 판별 조건

```
1. 코스피200 편입 (대형주)
2. 유효 분기 >= 28분기 (7년 이상 데이터)
3. 영업이익_1y_% 시계열에서 zero-crossing >= 2회
4. crossing 간격 = 유효분기 / crossing 횟수 ± 허용 오차
5. 글로벌 경쟁력 보유 업종
```

### 글로벌 경쟁력 인정 업종

| 업종 | 기준 |
|------|------|
| 반도체/전자부품 | 세계 시장점유율 또는 기술 독점성 |
| 자동차/부품 | 글로벌 완성차 또는 1차 벤더 |
| 조선 | LNG선 등 고부가 선종 경쟁력 |
| 방산 | K방산 수출 실적 및 수주잔고 |
| 철강/소재 | 글로벌 특수재 또는 비철금속 1위 |
| 2차전지소재 | 글로벌 양극재/음극재/동박 |

### 제거 업종

```
통신, 플랫폼, 바이오, 유통, 건설(국내), 화장품
→ 글로벌 사이클 비연동 or 글로벌 경쟁력 미흡
```

## 2. 핵심 신호 정의

### Signal 1: 싸다 (per_ratio < 1.0)

```
per_ratio = per_20d_mean / per_4y_mean

per_ratio < 1.0  →  signal1 = 1 (싸다)
per_ratio > 2.0  →  매도 검토 구간
```

- `per_4y_mean`: 최근 4년 평균 PER (ni → op → rev 순 우선순위)
- `per_20d_mean`: 최근 20일 평균 주가 기준 PER

### Signal 2: Capex 증가 (capex_ps_yoy_pct > 0)

```
capex_ps_yoy_pct > 0  →  signal2 = 1
→ 설비투자 확대 = 다음 사이클 준비
```

### Signal 3: 영업이익 회복 (op_ps_yoy_pct > 0)

```
op_ps_yoy_pct > 0  →  signal3 = 1
→ signal2의 후행 확인 지표
```

## 4. Streak (신호 연속 분기) 패턴

### 정의

```
streak = 핵심신호가 연속으로 켜진 분기 수
streak 1 = 이번 분기 처음 켜짐 (진입 타이밍)
streak N = N분기 연속 유지 중
```

### 유형별 전략

| 유형 | 패턴 | 해당 종목 | 전략 |
|------|------|----------|------|
| 초입형 | streak 1~2 가 최적 | 삼성전자, SK하이닉스, 기아, DB하이텍, 이수페타시스 | 신호 첫 진입 즉시 매수. 길어지면 비율 모니터링 |
| 장기형 | streak 길수록 강함 | 한화에어로스페이스, 현대로템, LIG넥스원, HD한국조선해양, 현대차 | 초입 진입 후 장기 홀딩. 사이클 구조적 지속 |
| 중간형 | streak 3~5 최적 | 두산에너빌리티, HD건설기계, 고려아연 | 초입 약함. streak 3 이후부터 의미있음 |

### 핵심 원칙

```
초입에 진입 → 신호 유지되는 한 홀딩
유형 구분은 참고용 → 사전에 알 수 없음
결국 진입 후 홀딩이 기본 전략
```

## 5. 매수 기준

```
조건 1: 핵심신호 ON
  s1 종목 → per_ratio < 1.0
  s2 종목 → capex_ps_yoy_pct > 0

조건 2: streak 1~2 (첫 진입 구간 우선)

조건 3: per_ratio 확인
  < 1.0   → 강력 매수
  1.0~1.5 → 매수 가능
  1.5~2.0 → 신중 매수
  2.0+    → 진입 자제 (예외: 사이클 초입 + 신호 강력)
```

### 매수 타이밍 교과서

```
경기 저점 = 이익 바닥 = PER 고점 or 적자
→ per_ratio 낮음 (4년 평균 대비 현재 싼 상태)
→ Capex 증가 전환 (다음 사이클 투자 시작)
이 두 조건 겹치는 시점이 최적 매수
```

## 6. 홀딩 기준

```
핵심신호 ON 유지  →  홀딩
per_ratio < 2.0  →  홀딩
per_ratio 2.0+   →  유형 확인
  장기형 + 신호 ON  →  홀딩 유지
  초입형 + 신호 ON  →  주의 홀딩. 신호 꺼지면 즉시 검토
```

---

## 7. 매도 기준

```
1순위: 핵심신호 OFF + per_ratio > 2.0  →  매도
2순위: 핵심신호 OFF (신호만 꺼진 경우)  →  매도 검토
3순위: per_ratio > 2.0 단독            →  장기형은 홀딩, 나머지 매도 검토
```

### per_ratio 구간별 12m 수익률 참고

| 구간 | n | 12m mean | 12m median | -20% 이하 비율 |
|------|---|----------|------------|---------------|
| 매수권 (<0.5) | 270 | 42% | 18% | 17% |
| 적정하단 (0.5~1.0) | 470 | 37% | 15% | — |
| 적정상단 (1.0~1.5) | 261 | 18% | 0% | — |
| 비싼 (1.5~2.0) | 92 | 16% | 4% | — |
| 극단 비쌈 (2.0+) | 136 | 34% | 17% | 25% |

> 2.0+ 구간 mean이 높은 이유: 사이클 진행 중인 종목이 섞여 있기 때문. 신호 OFF 종목은 걸러야 함.

## 9. 워크플로우

```
커서 (데이터 추출)
  ↓
CSV (per_ratio, streak, 신호 ON/OFF, 수익률)
  ↓
Claude (패턴 분석 + 종목 판단)
  ↓
매수/홀딩/매도 리스트
```

### 커서에서 필요한 파생 변수

```python
per_ratio = per_20d_mean / per_4y_mean
s1_streak = 연속 signal1 분기 수
s2_streak = 연속 signal2 분기 수
s1_entry  = signal1 0→1 전환 여부 (진입 타이밍)
s2_entry  = signal2 0→1 전환 여부
```
